A program that sums up the world news of Tuesday 17 November 2026 in one image: a three-panel editorial illustration of the Kerch Bridge strike, the burning tankers near the Strait of Hormuz, and the confirmed Xi–Trump–Putin meeting in Shenzhen.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the image to `out/entry.png` (1024×1024 JPEG, 237,441 bytes, deterministic: two runs write identical bytes).
